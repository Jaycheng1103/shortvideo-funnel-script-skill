# 個人品牌八個問題

用途：第二步訪談。照順序一題一題問，每題有兩個小問題，可以挑比較好答的先問。

題目由傑少（無界聯盟）整理成八組，部分改寫自 Dan Koe 談個人品牌的問題。

| 順序 | 主題 | 問題 |
|---|---|---|
| 1 | 你要幫誰 | 用「一個人」來描述他。他糟糕的一天長什麼樣？ |
| 2 | 你要帶他去哪裡 | 跟著你五年後，他的日常長什麼樣？他會驕傲地寫下什麼身分？ |
| 3 | 你的故事 | 你活過哪些他正在活的事？事情轉折的那一刻是什麼？ |
| 4 | 你反對什麼 | 你想幫他們逃出怎樣的人生？你想消滅哪一個迷思或習慣？ |
| 5 | 使命與信念 | 用一句話說，你想幫人做到什麼？你相信、但圈內多數人不信的是什麼？ |
| 6 | 誰形塑了你的想法 | 哪些書、貼文、影片你從不跳過？誰改變了你的思考？ |
| 7 | 獨特觀點 | 什麼事你能講好幾個小時？你切入的方式跟別人有什麼不同？ |
| 8 | 為什麼是現在 | 世界上剛發生、但多數人還沒注意到的是什麼？ |

八個答案加起來，就是他獨一無二的個人品牌。

## 問法提醒

- 對電商老闆，「幫誰」通常就是他的主要客人，可以先從「最常回購的那位客人」問起。
- 「你的故事」最常卡住。可以改問：「你為什麼開始賣這個？開店到現在，最想放棄的是哪一次？」
- 答案越像對朋友講話越好。他講得很書面時，請他「用講給客人聽的方式再說一次」。
