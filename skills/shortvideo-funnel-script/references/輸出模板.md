# 輸出模板

## 產品素材表（商品短影音第 1 步結束時）

| 項目 | 他的答案重點（盡量用原話） | 狀態 |
|---|---|---|
| 賣什麼、價格、在哪買 | | 已答／待補 |
| 賣給誰 | | |
| 買之前卡在哪、常問什麼 | | |
| 為什麼選你 | | |
| 手上的素材 | | |
| 平台與長度 | | |

最後一行問：「這樣對嗎？有要補的嗎？沒問題我就給你 30 個方向。」

## 方向清單（商品短影音第 2 步）

分吸引、信任、成交三段，每段一張表：

| # | 方向 | 題目 | 用到的素材 | 缺什麼 |
|---|---|---|---|---|
| 1 | 清單 | 「＿＿」 | 客人最常問的三個問題 | 無／待補客人照片 |

不建議的方向，題目欄寫「不建議」和一句原因。

列完寫：我推薦先拍這 3 個（各一句理由），你想挑哪幾個？

## 腳本（個人故事第 2 步、商品短影音第 3 步）

一律照五段寫，段落名稱不改、不跳段；缺的段落寫「待補」，並寫出要問他的那一題。

```
題目：
路線：個人故事／商品短影音（方向：＿＿，層：吸引／信任／成交）
主角：　　　　　預估長度：（估算，念完再調）

【鉤子】為什麼我該在意？
第一句：（先講痛，再講好處）
第二句｜憑什麼：成果型／投入型／研究型
出處：（研究型必填；找不到寫「待查證」）
畫面：　　　字卡：

【背景】我們在哪裡
台詞：　　　畫面：　　　字卡：

【挑戰】哪裡卡住了
台詞：　　　畫面：　　　字卡：

【行動】什麼改變了（讓事情轉彎的人或事件：＿＿）
台詞：　　　畫面：　　　字卡：

【收穫】所以呢，觀眾能帶走什麼
結果｜台詞：
帶走｜台詞：（個人故事、吸引、信任：一句帶得走的話或一個問題；成交：賣什麼、怎麼買、連結在哪）
畫面：　　　字卡：

待補／待查證：
```

寫完附一句：拍前請念一遍，改成你自己會說的話。
