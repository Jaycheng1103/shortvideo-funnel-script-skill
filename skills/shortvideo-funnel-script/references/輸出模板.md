# 輸出模板

## 品牌答案表（第二步結束時）

| 題目 | 他的答案重點（盡量用原話） | 狀態 |
|---|---|---|
| 1 你要幫誰 | | 已答／待補 |
| …… | | |

## 題目清單（第三步）

分 TOFU、MOFU、BOFU 三段，每段一張表：

| # | 格式 | 題目 | 用到的素材 | 角色 | 缺什麼 |
|---|---|---|---|---|---|
| 1 | 清單型 | 「＿＿」 | 第 3 題故事／某產品 | 痛點鉤子（導流型） | 無／待補客人照片 |

最後一行寫：建議先拍哪五題（週一到週五各一題）。

## 腳本（第五步）

```
題目：
格式：　　　　　角色：　　　　　預估長度：（估算，念完再調）

【Hook】
0–3 秒｜台詞：（第一句：落差）
　　　　畫面：
3–6 秒｜台詞：（第二句：憑什麼）
6–9 秒｜台詞：（第三句：鋪墊）

【證據】類型：成果型／投入型／研究型
台詞：
出處：（研究型必填；沒有就寫「待查證」）

【內容】
段落 1｜台詞：　　　畫面：　　　字卡：
段落 2｜……

【結尾】
台詞：

拍前請核對：
待補／待查證：
```

寫完附一句：拍前請念一遍，改成你自己會說的話。
