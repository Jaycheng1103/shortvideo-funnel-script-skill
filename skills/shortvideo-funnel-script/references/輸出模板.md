# 輸出模板

## 品牌答案表（第二步結束時）

| 題目 | 他的答案重點（盡量用原話） | 狀態 |
|---|---|---|
| 1 你要幫誰 | | 已答／待補 |
| …… | | |

## 題目清單（第三步）

分 TOFU、MOFU、BOFU 三段，每段一張表：

| # | 格式 | 題目 | 用到的素材 | 角色 | 缺什麼 |
|---|---|---|---|---|---|
| 1 | 清單型 | 「＿＿」 | 第 3 題故事／某產品 | 痛點鉤子（導流型） | 無／待補客人照片 |

最後一行寫：建議先拍哪五題（週一到週五各一題）。

## 腳本（第五步）

一律照七段寫，段落名稱不改、不跳段；缺的段落寫「待補」。

```
題目：
格式：　　　　　角色：　　　　　故事主角：　　　　　預估長度：（估算，念完再調）

【1 Hook】（先講痛，再講好處）
台詞：
畫面：　　　　　字卡：

【2 Super Hook】類型：成果型／投入型／研究型
台詞：（第二句：憑什麼）
台詞：（第三句：鋪墊，真實經過）
出處：（研究型必填；沒有就寫「待查證」）

【3 背景】
台詞：　　　畫面：　　　字卡：

【4 低谷】
台詞：　　　畫面：　　　字卡：

【5 轉折點】遇到了誰：
台詞：　　　畫面：　　　字卡：

【6 付出努力】
台詞：　　　畫面：　　　字卡：

【7 收穫成果】
外在成果｜台詞：　　　畫面：
內在轉變｜台詞：
收尾｜（導流型：一句帶走的話或一個問題；導購型：賣什麼、怎麼買、連結在哪）

拍前請核對：
待補／待查證：
```

寫完附一句：拍前請念一遍，改成你自己會說的話。
