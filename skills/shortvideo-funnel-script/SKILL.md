# 短影音漏斗腳本發想

這個 Skill 把「今天要拍什麼？」變成一套固定流程：資料 → 訪談 → 28 個題目 → 選題 → 七段腳本。

核心觀念：短影音不是發越多越好，而是每一支在漏斗裡各有位置。老闆的影片負責把陌生人帶進來（導流型），電商的影片負責接住成交（導購型）。題目不能只繞著產品打轉，要把老闆本人的故事、經歷和觀點放進去，這才是別人抄不走的部分。

## 開始前

- 用繁體中文、台灣自然口語。一次只問一題，等對方回答再問下一題。
- 只用對方給的真實資料。沒講過的經歷、數字、客戶成果、研究，一律不補；需要卻沒有的，標「待補」或「待查證」。
- 對方的回答與產出預設只留在對話。要存檔時，先問存在哪裡。

## 只想寫創辦人起源故事時

對方說「我想拍我為什麼開始做這個品牌」「幫我寫創辦人故事」時，走短的流程：

1. 第一步收資料只問「賣什麼、賣給誰」兩樣。
2. 第二步八個問題照樣一題一題問，第 1 題（你要幫誰）和第 3 題（你的故事）一定要問到有具體畫面。
3. 跳過 28 個題目，改成提出 3 個起源故事的切入角度（例如從最痛的那一刻切、從客人的一句話切、從一個反差切），每個角度一句話當標題，讓他選一個。
4. 讀 `references/創辦人起源故事.md`，照七段結構（Hook → Super Hook → 背景 → 低谷 → 轉折點 → 付出努力 → 收穫成果）寫成腳本，用輸出模板的「腳本」格式交付。

## 流程

### 第一步：收資料

先問清楚下面幾樣，缺的就問（一次一題）：

1. 賣什麼：產品或服務、價格帶、在哪裡買（官網、蝦皮、門市、LINE）。
2. 賣給誰：主要客人是誰、他們買之前最常卡在哪裡、最常問什麼問題。
3. 手上有什麼素材：客人回饋、前後對比、幕後過程、常見問答、合作或得獎紀錄。
4. 平台與頻率：主要發在哪個平台，一週能拍幾支。

### 第二步：個人品牌訪談（八個問題）

讀 `references/八個問題.md`，照順序一題一題問。每題問完，用一兩句複述他的答案，確認沒聽錯再往下。答得太短就追問一次「可以舉一個真實發生過的例子嗎？」，還是沒有就記「待補」，不要替他編。

八題問完，整理成一張「品牌答案表」：每題一行，寫他的原話重點。

### 第三步：出 28 個題目

讀 `references/28種格式.md`，每一種格式各出一個題目，共 28 個，照 TOFU、MOFU、BOFU 分三段列。用 `references/輸出模板.md` 的「題目清單」格式，每個題目都要寫：

- 題目（一句話，像影片標題）
- 用到哪一題的答案或哪一樣產品素材
- 在漏斗的位置：導流型或導購型，對應五種角色（痛點鉤子、品牌幕後、商品導購、客戶見證、化解疑慮）
- 缺什麼素材才拍得出來

規則：

- 28 題裡，至少一半要用到第二步的個人答案，不能全部都在講產品。
- 某個格式真的配不上他的生意，照實寫「這個格式不建議」和原因，不要硬湊。
- 題目要具體到他看了就知道要拍什麼。「分享創業心得」太空，「加盟兩次賠掉四百萬之後，我決定做自己的產品」才算。

### 第四步：讓他選

列完 28 題，請他挑 1 到 5 題先寫。他不知道怎麼挑時，建議一週五支一輪：週一痛點鉤子、週二品牌幕後、週三商品導購、週四客戶見證、週五化解疑慮，各挑一題。

### 第五步：寫腳本

讀 `references/腳本結構.md`。每一支腳本都照這七段寫，不管是哪一種格式，段落不跳、不合併：

1. **Hook**：開頭第一句先講痛，再講好處（落差）。一般開頭只講好處，從 0 走到 +100；先講痛是從 −100 走到 +100，落差變兩倍。
2. **Super Hook**：第二句講你憑什麼說這句，從成果型（你做到了什麼）、投入型（你花了多少功夫）、研究型（借機構或研究的公信力）挑一種他手上真的有的；第三句加一句真實的鋪墊，接進背景。用研究型時先做資料調查：找得到可回查的原始出處（研究、政府統計、機構報告）才用，寫上出處名稱與年份；找不到就改用成果型或投入型，或標「待查證」。
3. **背景**：一開始是什麼狀況，一個具體畫面。
4. **低谷**：最卡、最痛、差點放棄的那一刻，時間、金額或對話至少一樣具體。
5. **轉折點**：遇到了誰，產生了轉折。一定要有人或事件，不能只寫「後來想通了」。
6. **付出努力**：轉折之後做出了什麼樣的努力，寫動作和數字。
7. **收穫成果**：外在成果加內在轉變。最後依漏斗位置收尾：導流型收在一句可以帶走的話或一個問題；導購型才講怎麼買、連結在哪。

格式決定「誰的故事」和「畫面怎麼拍」（見 `references/28種格式.md` 每一格的「怎麼排」與 `腳本結構.md` 的套用表）：痛點鉤子、品牌幕後講創辦人，客戶見證講客人，商品導購、化解疑慮講產品或第一個用的客人。清單、打分數、對比這類格式，主體內容放在第 6 段展開。

用 `references/輸出模板.md` 的「腳本」格式交付：每段的台詞、畫面、字卡。寫完附一句「拍前請念一遍，改成你自己會說的話」，並列出所有「待補」「待查證」的地方。

## 不做的事

- 不保證流量、觀看數或成交。
- 不拿別人的影片、圖片、商標當素材；參考別人的格式可以，內容要放他自己的。
- 不寫醫療、療效、投資報酬等需要法規或證據支撐的保證句；碰到時提醒他先確認法規。
